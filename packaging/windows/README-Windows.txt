ops-agent 中台 Windows 版

【安装】
1. 把压缩包整个解压到一个固定的可写目录(如 D:\OpsAgent),不要放 Program Files,不要直接在压缩包里运行。
   若双击时 Windows 提示「已保护你的电脑」:右键压缩包 → 属性 → 勾选「解除锁定」后重新解压(内部使用,exe 未做代码签名)。
2. 双击 OpsAgent.exe:右下角托盘出现圆点图标,中台自动启动,就绪后用浏览器打开控制台。
   首次启动会建立知识索引,约十几秒。包内不带环境数据与知识库,接真实环境见下方【环境数据】。
3. 圆点颜色:绿=运行中,黄=启动中/停止中/无响应,红=启动失败,灰=已停止;右上角蓝点=有新版本。
4. 左键点托盘图标弹出面板:启动/停止/重启中台、打开控制台、检查与安装更新、登录后自动启动、查看日志。
   右键菜单:打开面板 / 打开控制台 / 检查更新 / 退出(停止中台)。
   Win10 新图标默认收在任务栏 ^ 里,可以把它拖到任务栏上常驻显示。
5. 外壳已在运行时再双击 OpsAgent.exe 不会多开,只弹出面板(中台停着会顺便拉起)。

【目录】
- app\<版本>\    程序本体(Python 运行时 + 代码 + 前端),更新整体替换,不要改里面的文件
- app\current    当前版本号
- data\          本机数据:env(环境数据)、knowledge、records、state、build 与 config(模型、凭据、插件、更新设置),更新永不触碰
- shell\         外壳日志 shell.log、面板缓存与更新下载

【更新】
- 面板「更新设置」填发布仓(owner/name)与只读 token(私有仓需要);外壳启动 1 分钟后检查一次,之后每 6 小时,也可手动检查。
- 有新版本时托盘图标出现蓝点;点面板「更新」才会下载、校验签名并切换,有排查任务进行中会先确认。
- 新版本 3 分钟内起不来会自动退回上一版并恢复 state;面板显示失败原因,详情看 data\state\web_server.log。

【环境数据】
- 包内只带虚构的示例环境(控制台顶部提示「当前为示例环境」)。接真实环境:把环境包目录放到 data\env\,
  知识库放到 data\knowledge\(git clone 或从旧机器整目录拷贝),然后在面板重启中台。更新不碰这两个目录。
- 从旧机器搬配置与设置的完整清单:app\<版本>\docs\migration.md。

【首次使用】
- 在控制台「设置」里填模型、节点凭据、插件等凭证。它们只存在本机 data\config 下,不在包里。

【注意】
- 中台运行期间阻止电脑自动睡眠;关机或注销后中台停止,开了「登录后自动启动」的话重新登录会自动拉起。
- 启动失败时面板显示原因;中台日志 data\state\web_server.log,外壳日志 shell\shell.log。
